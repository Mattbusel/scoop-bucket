# Mattbusel Scoop bucket

Prebuilt Windows tools by [Matt Busel](https://github.com/Mattbusel), installed with [Scoop](https://scoop.sh).

```powershell
scoop bucket add mattbusel https://github.com/Mattbusel/scoop-bucket
scoop install mattbusel/<tool>
```

Manifests live in `bucket/` and point at each tool's GitHub Releases, with SHA-256 checksums.
